# 売上報告アプリ

HTML・CSS・JavaScriptだけで動く、GitHub Pages向けの静的Webアプリです。

## 商品の変更

`products.json` をテキストエディタで開き、現在使用する商品の追加・変更・削除を行います。

- `products.json`: 最初に表示される新商品メニュー表
- `products-old.json`: 切り替えて確認できる旧商品メニュー表

画面の「旧商品メニュー表に移動」ボタンで2つのメニュー表を切り替えられます。メニューごとの入力内容は別々に保持されます。

「販売可能商品を一括変更」では、店内販売・移動販売ごとに `−100`・`−10`・`−1`・`＋1`・`＋10`・`＋100` のボタンで販売可能な商品の数量を一括変更できます。「販売なし」など文字表示の商品は対象外で、減算しても0未満にはなりません。

「商品効果早見表に移動」ボタンを押すと、`effect.html`のラーメン・ドリンク早見表を別ページとして表示できます。

「請求額を計算」ボタンを押すと、現在表示中のJSONの商品名と価格を使ったお会計画面が開きます。商品ごとの個数を入力すると合計が自動計算され、合計金額をクリックするとコピーできます。
お会計画面の「上限 ＋○個」を押すと、その商品の1人分の販売上限を数量へ追加できます。店内販売不可の場合は、移動販売の数値上限を使用します。
「売り上げ報告に反映」を押すと、お会計の数量を現在の売上報告へ加算し、お会計側の数量をすべてクリアします。

```json
{
  "id": "regular",
  "name": "通常メニュー",
  "products": [
    { "id": "egg-sand", "商品名": "たまごサンド", "tag": "おすすめ", "価格": 500, "店内": 100, "移動販売": 100 }
  ]
}
```

- グループの `id`: メニュー区分ごとに重複しない半角英数字のID
- グループの `name`: 「通常メニュー」などの見出し
- 商品の `id`: 商品ごとに重複しない半角英数字のID
- 商品の `商品名`: 表に表示する商品名
- 商品の `tag`: 商品名の横に表示する短い補足。空文字なら表示しません
- 商品の `価格`: 1個あたりの価格を0以上の整数で指定
- 商品の `店内`: 店内販売の上限数、`"上限なし"`、または状態を表す文字
- 商品の `移動販売`: 移動販売の上限数、`"上限なし"`、または状態を表す文字

文字を設定する例：

```json
{
  "id": "egg-sand",
  "商品名": "たまごサンド",
  "価格": 500,
  "店内": "販売なし",
  "移動販売": "上限なし"
}
```

- 数値：参考値として画面に表示します。入力数の制限には使用しません。
- 数値が設定された販売区分では、各商品の「上限」ボタンを押すと1人分の上限数を現在の個数へ追加できます。
- `"上限なし"`：上限を設けず入力できます。
- それ以外の文字：入力欄の代わりに、その文字を表示します。

## ローカルで確認

`products.json` を読み込むため、`index.html` を直接ダブルクリックするのではなく、
ローカルWebサーバーから開いてください。

Pythonがある場合：

```powershell
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## GitHub Pagesで公開

1. このフォルダーのファイルをGitHubリポジトリへ登録します。
2. リポジトリの「Settings」→「Pages」を開きます。
3. 「Deploy from a branch」を選択します。
4. 公開元を `main` ブランチの `/ (root)` に設定します。

以後、`products.json`または`products-old.json`を更新してGitHubへ反映すると商品情報も更新されます。
